## 证据状态

本批实际完成了 20/20 条件、40 个源侧选中的模型、400 个候选头和 400 个新预测格；另外复用并重算了 1000 个已锁定历史对照格。模型和全部新预测先全局封存，之后才读取 target-dev 标签；target-train 故障标签、跨域同步窗口、target-final 信号和标签均未用于本批结果。独立核验报告为 `audit/kernel_baselines_integrity_20260918.json`，状态 `passed`，覆盖 400 个候选、40 个模型、1400 个指标格及 84 个聚合行。

原冻结核验器曾在第一个出现的 SEU RBF 模型上要求选中 logits 与候选缓存逐元素完全相等而失败。独立数值诊断最大绝对差为 `2.74e-15`、相对差约 `7.31e-11`，来自 float64 批处理/矩阵运算顺序；没有类别预测差异。保留原冻结文件不改，新增 `verify_kernel_baselines_20260918.py` 仅将这一处回放容差固定为 `1e-12`，并验证原冻结核验器哈希仍与计划一致；该审计通过。它不是放宽模型选择或指标计算，也没有重新训练。

关键结论：

- RBF-KRR 的全20条件等权 clean 平均为 62.517/60.082，低于 raw Ridge 的 68.827/67.682；在实验室齿轮箱 clean 平均低 22.834 Acc 点、25.024 F1 点。按数据集内部均值，水泵为64.556/61.359，实验室齿轮箱为52.833/49.988，东南大学为68.250/66.694；它只在部分条件有效，不能作为统一模型。
- 源验证选参线性 Ridge 相对 raw Ridge 的全20条件等权 clean 平均仅提升 0.210 Acc 点、0.150 F1 点；20 dB提升0.576/0.518点，10 dB提升1.674/1.749点，0 dB提升0.897/1.183点，但并非每个数据集/家族都提高。这说明此前强基线的优势不是简单由 alpha=1 偶然造成，也没有证明需要非线性核头。
- RBF 在 0 dB 实验室齿轮箱 Acc 高于 raw Ridge 约 5.056 点，但 Macro-F1 低约 3.669 点，不能只用准确率宣传鲁棒性。东南大学 RBF clean 的收益在 10/0 dB 消失，不能称普遍抗噪。
- 单通道结果仍应逐槽报告；本批完整逐条件、家族、逐类召回和混淆矩阵在 `CONDITIONS.md` 与 `condition_summary.json`，不能以数据集均值替代弱槽结论。

## 对原四项目标的影响

这批结果补齐了必要的经典非线性对照，但没有完成一个统一优于 Ridge/WIDAN 的新模型。因此“新颖高性能 UDA 方法”主张仍不成立。20条件主矩阵包含3→3及同工况3→1；随后独立的 `20260918_kernel_3to1_expansion_v1` 已另行补齐代表性跨工况/双跨3→1，不能把两个批次混成一张未经标注的主表。

噪声实验验证了原始波形 AWGN、20/10/0 dB 和三个噪声种子下的表现，但噪声种子只代表加噪随机性，不是训练随机性或独立采集重复。已有受扰统计校准批次仍显示收益依赖代表性无标签校准池，不能写成未知工业噪声普遍抗噪。

## 下一步

停止继续扫 RBF 参数或堆叠新模块；完整网格已证明主要瓶颈不是“缺一个经典非线性分类头”。下一项应围绕可解释的测点/工况响应差异，固定一个机制假设后只改一个因素，并在源选模、20 条件、逐槽指标和已有噪声协议下重新冻结。投稿定位可以是严格无标签跨传感器故障诊断的受控经验研究/失败边界；若坚持新算法论文，还需要独立机制、训练多种子和更强的跨记录验证。
